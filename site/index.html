Your code is the source of truth. Your README should be too.

A Claude skill that writes READMEs from your code, then checks every command, env var and path in them against the repo. It also designs banners and GitHub profile pages.

claude plugin install readme-forge --marketplace tanmayai23/README-Editor-skill

Then, in Claude Code: /readme-forge write a README for this repo

How it works

  1. 1

    Reads your repo

    Manifests, lockfiles, scripts, env vars, Docker, CI and routes.

  2. 2

    Writes from facts

    Only what it can point to in a file, and a TODO where it can't.

  3. 3

    Checks every claim

    Commands, scripts, flags, env vars and paths against the code, in Claude Code or in CI with a GitHub Action.
